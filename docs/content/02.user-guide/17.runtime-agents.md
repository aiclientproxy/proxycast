# 运行时 AGENTS 规则

Lime 应用运行时会话不读取仓库根 `AGENTS.md`，而是使用 `.lime/AGENTS.md` 体系。

## 当前事实源

运行时 AGENTS 相关能力分成两层：

- 全局：`~/.lime/AGENTS.md`
- 工作区：`<workspace>/.lime/AGENTS.md`

这两层会直接进入 Lime 运行时 AGENTS 提示拼接。

## 当前加载口径

默认情况下，可以按下面这条顺序理解：

1. 先读全局：`~/.lime/AGENTS.md`
2. 从项目根到当前工作目录逐层读取工作区规则
3. 同一层如果存在 `.lime/AGENTS.override.md`，用它替代 `.lime/AGENTS.md`

推荐分工：

- `~/.lime/AGENTS.md`
  - 放长期个人偏好
- `<workspace>/.lime/AGENTS.md`
  - 放团队共享的项目规则
- `<workspace>/.lime/AGENTS.override.md`
  - 临时替代同目录的 `.lime/AGENTS.md`

## 注意事项

- Lime 运行时不会读取仓库根 `AGENTS.md`
- 工作区规则从项目根到当前工作目录按目录层级加载
- 如果团队要共享规则，请提交 `.lime/AGENTS.md`
- `AGENTS.override.md` 与 Codex 一致，是同目录 `AGENTS.md` 的替代项，不是叠加层

## 最小示例

`~/.lime/AGENTS.md`

```md
# 我的全局 Lime 运行时规则

- 默认使用中文简体
- 先给结论，再给关键步骤
- 没必要时保持简洁
```

`<workspace>/.lime/AGENTS.md`

```md
# 当前项目运行时规则

- 先读后写
- 只改当前任务直接相关内容
- 若无法完整验证，需要明确说明
```
